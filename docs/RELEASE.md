# 0.33 启动修复范围

用户反馈冷启动残留旧侧栏与白/灰背景。根因是原生 WebView 默认白底且 onCreate 立即展开旧抽屉，基础 CSS 仍使用旧浅色配色。

统一 Window/容器/WebView/HTML 首帧深色；启动直接进入 3D，菜单改为按需打开，原关卡/难度/声音/提示/存档/签名和更新路由保持。基础样式不再保留浅色 2D 外观，隐藏的棋盘 DOM 仍是游戏状态载体，不能删除破坏规则。渲染加载或上下文丢失期间冻结游戏 tick，避免直达棋盘后在不可见时损失时间；恢复后继续，不建立第二个计时器。

影响与验证：冷启动、慢加载/渲染失败、首帧颜色，菜单开关与暂停、后台/前台、关卡与提示、旧数据同签覆盖；保持更新只在明确打开菜单时自动检查。用现有游戏/更新测试、针对渲染等待的时钟回归及真机启动逐帧检查验证；本次不重建 3D 资产或改流体。

完整 lint 另发现英文/日文仅含同值应用名的冗余资源，把它们误报为未完整翻译的语言。移除两份与默认英文完全相同的 launcher_label，英文及其他非中文系统继续使用默认 PipePanic，中文名称与现有中/英界面不变；完整 lint 重新通过，未增加忽略项。手机 screenrecord 写入被系统拒绝，启动验证使用连续截图采样（不是逐视频帧的全覆盖证明）。

## 0.32 正式版基线

基于已验证的 0.31-QA 顶视 3D 游戏。保留经典/无限练习、编号挑战、20 个固定关卡、每日挑战、撤回、提示开关、音效、语言和全屏安全区域；不引入 Unity、重力或真实流体样板。

本轮仅更新应用图标、版本、正式分发配置与签名更新入口。图标须适配圆形/方形桌面裁切；旧设备保留分辨率资源。更新只允许在前台且主菜单完全打开、没有对局/帮助/弹窗时自动检查。关于页可手动检查。进入对局、后台或销毁必须取消请求和定时器；迟到响应不得弹窗。失败保持安静，手动失败说明原因；单飞、去重、持久化、签名/身份/时效/回滚验证沿用已验证模块。

不改变既有游戏存档键及关卡规则。Android 正式包与 QA 包分开，不能用不同证书覆盖用户原版。正式证书和网站产品绑定在打包前核对；私钥只存在受保护外部存储。新增联网仅用于浩科版本检查，不添加后台服务、统计或自动安装。

验收：原有 14 项游戏测试；更新模块签名与生命周期测试；最终 APK 身份/证书/图标检查；真机冷启动、菜单、提示摆放/试水、暂停/恢复、关于页和更新检查。完整素材、许可和生成源保存在 art/。
